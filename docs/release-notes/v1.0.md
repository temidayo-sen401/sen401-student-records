# Student Records v1.0 — Initial Baseline

First configuration baseline of the Student Records project (SEN 401, Lab 1).

## Contents
- `app.py`: demo application entry point
- `students.py`: student data module (in-memory list, `average_score`, `add_student`)
- `utils/helpers.py`: `highest_score`, `lowest_score`, `pass_rate`
- `tests/`: baseline pytest suite
- `.github/workflows/ci.yml`: CI runs tests and the demo on every push/PR to `main` and `dev`

## Branching model
- `main`: protected, release-ready baselines only (changes via reviewed PR)
- `dev`: integration branch
- `feature/*`: new features, merged into `dev`
- `maint/*`: maintenance work against a released baseline

## Known limitations (to be addressed in maintenance)
- No input validation on student records.
- Helper functions are untested against an empty student list.
