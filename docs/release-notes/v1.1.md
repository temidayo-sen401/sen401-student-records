# Student Records v1.1 — Maintenance Release

Maintenance baseline produced on the `maintenance` branch (SEN 401, Lab 2).
**Requires Python 3.12+.**

## Corrective (#3) — `4c537cc`
- `students.py` no longer prints on import (the output appeared twice in v1.0).
- `highest_score` / `lowest_score` return `None` and `pass_rate` returns `0.0` for an empty list instead of crashing.
- Invalid scores (text, negative, over 100) are rejected instead of breaking `average_score` later.

## Adaptive (#4) — `d26a69d`
- Upgraded to Python 3.12: PEP 695 `type` alias and modern `X | None` type hints. CI now runs on 3.12.
- New Pydantic v2 `Student` model validates name and score (strict number, 0-100).
- `pydantic==2.14.3` added to `requirements.txt`.

## Perfective (#5) — `818d1de`
- New statistics: median, standard deviation, letter grade and `score_summary()`.
- `app.py` prints a formatted, ranked report table.

## Preventive (#6) — `6bff7de`
- `students.py` refactored: functions take data explicitly, `default_students()` returns fresh data, and score limits are named constants.
- Docstrings and comments added throughout.

## Tests
The test suite grew from 5 to 29 tests, with a test file per maintenance type.
